B-L-CHECK

เทียบ B/L ที่ลูกค้าส่งมากับ DRAFT จากระบบ HAL ครบ 27 หัวข้อ รวม RIDER / AS PER ATTACHED แล้วออกรายงาน Excel แบบใส่สี จุดไหนไม่ตรงเห็นได้ทันทีก่อนออก B/L จริง

CLIENT B/L.pdf+ DRAFT HAL.pdf→ BL CHECK.xlsx
ตรวจออนไลน์ (ไม่ต้องติดตั้ง) ดาวน์โหลดโปรแกรม (ZIP) เปิดหน้า GitHub

ติดตั้งครั้งแรก

ทำครั้งเดียวต่อเครื่อง ใช้ Windows (ถ้าใช้แบบออนไลน์ ข้ามส่วนนี้ได้เลย)

  1. ติดตั้ง Python 3 จาก python.org/downloads

    หน้าแรกของตัวติดตั้ง ติ๊ก ☑ Add python.exe to PATH ก่อนกด Install Now

  2. ดาวน์โหลดโปรแกรม กดปุ่ม “ดาวน์โหลดโปรแกรม (ZIP)” ด้านบน

    คลิกขวาที่ไฟล์ ZIP → Extract All แล้วเก็บโฟลเดอร์ไว้ที่ไหนก็ได้ เช่น Documents

  3. รันครั้งแรกต้องต่ออินเทอร์เน็ต

    โปรแกรมจะติดตั้งไลบรารีที่ต้องใช้ (pdfplumber, openpyxl) ให้เองอัตโนมัติ

ใช้งานทุกครั้ง

  1. วางไฟล์ในโฟลเดอร์ input

    B/L ของลูกค้า 1 ไฟล์ และ DRAFT ของ HAL 1 ไฟล์ ชื่อไฟล์ต้องมีเลข B/L และไฟล์ DRAFT ต้องมีคำว่า DRAFT เช่น CLIENT HASLS22260901995.pdf กับ DRAFT HAL HASLS22260901995.pdf ใส่หลาย B/L พร้อมกันได้

  2. ดับเบิลคลิก run-bl-check.bat

    หรือดับเบิลคลิก open-bl-checker.bat เพื่อเปิดหน้าต่างโปรแกรม เลือกไฟล์ทีละคู่แล้วกด CHECK

  3. เปิดผลที่ output\BL CHECK <เลข B/L>.xlsx

    หน้าจอดำจะสรุปหัวข้อที่ไม่ตรงให้ด้วย ถ้าเปิดไฟล์ Excel ค้างไว้ ต้องปิดก่อนรันใหม่

RIDER / AS PER ATTACHED

  • หน้า 2 เป็นต้นไปของ PDF แต่ละฝั่ง อ่านเป็น RIDER ให้อัตโนมัติ
  • ถ้า RIDER เป็นไฟล์แยก ตั้งชื่อให้มีเลข B/L และคำว่า RIDER เช่น CLIENT RIDER HASLS22260901995.pdf, DRAFT HAL RIDER HASLS22260901995.pdf
  • เทียบ RIDER สองฝั่งทีละบรรทัด ทีละตู้ (SEAL, จำนวนหีบห่อ, น้ำหนัก) และยอดรวม KGS ที่เขียนใน RIDER
  • ถ้าฝั่งหนึ่งเขียน AS PER ATTACHED RIDER / SEE ATTACHED SHEET / AS PER ATTACHED DESCRIPTIONS แต่อีกฝั่งพิมพ์รายละเอียดไว้ในช่องนั้น จะไปหารายละเอียดใน RIDER ให้ เจอครบ = สีฟ้า ไม่เจอ = สีแดง
  • เขียน AS PER ATTACHED แต่ไม่มีหน้า RIDER = ขึ้นแดงพร้อมคำเตือน

เตือนเพิ่มเมื่อเจอ

  • เลขตู้ผิดหลักตรวจสอบ (ISO 6346)
  • GROSS WEIGHT น้อยกว่า N.W. ในรายละเอียดสินค้า
  • จำนวนตู้ใน TOTAL (IN WORDS) ไม่ตรงกับเลขตู้ที่ระบุ
  • เลข B/L ในชื่อไฟล์ไม่ตรงกับในเอกสาร
  • วันที่ ON BOARD หลังวันที่ออก B/L
  • เขียน AS PER ATTACHED แต่ไม่มีหน้า RIDER

ใช้กับ Claude Code
